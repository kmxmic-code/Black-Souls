# BKS — Timberclash & After Hours

Timberclash (a pixel forest fighting tournament) and BKS After Hours (a 3D survival horror in a shut-down arcade, `game/afterhours/`). This repository is the update server for the Windows launcher:

- `release.json` — the current version, patch notes, and a SHA-256 for every game file
- `game/` — the game files the launcher downloads (only the ones that changed)

Players don't need anything here: install the launcher once and it keeps itself up to date.
